# GitHub Pages 公開用

`index.html` をリポジトリの公開対象フォルダーに置いて、Settings → Pages から公開してください。

## 公開前の設定

`index.html` の `site-data` を編集します。

- `companyName`：会社名
- `contactEmail`：内見依頼を受信するメールアドレス
- `properties`：物件一覧。HTML内コメントの記入例を参照してください。
- 資料は `documents` フォルダーに保存し、物件の `documents` に名前と相対URLを記入してください。
- 物件の状態が変わったら `status` と `updatedAt` を修正し、GitHubへ保存します。

各物件のURLは `公開URL/index.html?property=bukken-001` の形式です。このURLをQR化してください。印刷後は物件のIDと公開URLを変えないでください。

## QRコードの作成

物件を登録して公開した後、次のコマンドで物件ごとのQR（`qr/物件ID.svg` と `.png`）を作成し、販売図面に貼り付けます。

```bash
pip install segno
python3 tools/make_qr.py https://公開ユーザー名.github.io/リポジトリ名/
```

## この版でできること

- 販売状況・最終確認日時の表示
- 公開資料の閲覧・保存
- 資料請求・内見依頼のメール作成（利用者がメールアプリで送信）

## この版には含まれないこと

管理画面による共有データの更新、内見依頼のサーバー保存、業者認証、自動通知、QR画像はブラウザ上では生成されません（下記スクリプトで作成）。これらのうち管理画面・サーバー保存・自動通知は別途サーバーが必要です。従来の管理画面付き試作版は別途保管しています。

GitHub Pagesへ置いた情報・資料は公開されます。社内資料・個人情報・申請者情報・パスワードを置かないでください。`noindex` は検索エンジンへの依頼であり、閲覧制限ではありません。

初期状態に物件や連絡先は登録していません。実際の情報を設定後、公開先でスマホ表示、資料リンク、メール作成を確認してください。
